# 办公保险库 — Tauri 桌面版（离线 exe）

网页版的桌面化升级：单个原生 exe（约 4.4 MB），使用系统自带 WebView2 渲染，无任何网络请求。
主界面顶部「密码 | 书签」页签切换：密码条目与书签树共存于同一个加密保险库（vault v2）。

## 使用

双击 `办公保险库.exe` 即可（Windows 10/11 自带 WebView2，无需安装运行时）。

- 数据文件默认保存在 **文档\密码保险库.vault**，可在「设置 → 数据文件」移动到其他位置（如 U 盘）
- 加密方案与网页版相同：AES-256-GCM + PBKDF2-SHA256（60 万次迭代），主密码无找回手段
- 条目支持 **API Key / 密钥类数据**：密码字段可选填（标签为"密码 / 密钥"），每个条目可添加任意**自定义字段**（Region、Secret ID、Endpoint 等），可标记"敏感"脱敏显示
- 密码生成器支持三种格式：混合字符集（登录密码）、**十六进制**、**Base64URL**（签名密钥/webhook secret）
- **导入 Chrome / Edge 导出的密码 CSV**：设置 → 导入浏览器密码，自动去重（相同网址+用户名跳过），统一打「浏览器导入」标签；导入后请删除明文 CSV
- **导出给浏览器**：设置 → 导出 CSV…，生成 Chrome 可直接导入的明文 CSV（仅含同时有网址和密码的条目），导入完成后请立即删除
- **书签区**：顶部页签切到「书签」——文件夹树（多级）、标签、搜索、打开链接；书签栏上方工具条支持 新建文件夹 / 导入 Netscape HTML（Chrome/Edge/Firefox 通用，合并去重或整库替换）/ 导出 HTML
- **旧书签库迁移**：设置 → 导入旧书签库，选择旧「书签管理器」的书签库 JSON（我的书签库.json），自动合并去重
- **批量管理**：列表上方「批量」按钮进入多选模式，密码可批量删除/设置分组与标签，书签可批量删除/移动
- **回收站**：删除先进回收站；密码 30 天后自动彻底清除，书签可随时恢复
- **密码历史**：修改密码自动保留旧值（最近 10 条），详情页可查看/复制
- **分组**：条目可设置分组（工作/个人/项目…），侧栏按分组筛选
- **条目模板**：新建时可选 服务器 SSH / 银行卡 / Wi-Fi / 软件许可 模板，预置字段
- **系统托盘**：点 ✕ 最小化到托盘（可在设置关闭），托盘左键或全局快捷键 Ctrl+Alt+V 呼出/隐藏窗口；托盘菜单显示收藏条目，点击直接复制密码（解锁后生效）
- 条目多时列表独立滚动，侧栏标签再多也不会把「设置/立即锁定」按钮挤出屏幕
- 桌面版特有：**窗口失焦自动锁定**（切到别的窗口立即锁，打开文件对话框时不会误锁，可在设置关闭）
- 数据文件每次改动原子写入（先写临时文件再改名），断电/崩溃不会损坏保险库

首次运行如遇 SmartScreen 提示，点「更多信息 → 仍要运行」即可（未签名 exe 的正常提示）。

## 目录结构

```
desktop/                     ← 本目录（仓库子目录）
├── 办公保险库.exe            ← 交付的可执行文件（复制自 target/release）
├── ui/index.html            ← 前端界面（密码区 + 书签区）
├── src-tauri/
│   ├── src/main.rs          ← Rust 端：文件原子读写、路径管理、原生对话框、系统托盘
│   ├── tauri.conf.json      ← 窗口/打包配置
│   └── icons/               ← 由 app-icon.png 生成
├── app-icon.png             ← 图标源文件（1024×1024）
└── icon-src.html            ← 图标的网页渲染源
```

## 开发与构建

环境要求：Node 18+、Rust stable-msvc、MSVC Build Tools（本机已具备）、WebView2（Win10/11 自带）。

```bash
npm install
# 开发模式（热重载）
node node_modules/@tauri-apps/cli/tauri.js dev
# 构建exe（--no-bundle 跳过安装包，直接出绿色单文件）
node node_modules/@tauri-apps/cli/tauri.js build --no-bundle
# 产物：src-tauri/target/release/office-vault.exe
```

## 与网页版的差异

| | 网页版 | 桌面版 |
|---|---|---|
| 存储 | 浏览器 localStorage + 可选绑定文件 | 原生 .vault 文件（默认文档目录） |
| 失焦锁定 | 无 | 有（可开关） |
| 写入安全 | — | 临时文件 + 原子改名 |
| 文件对话框 | 浏览器 API | 原生对话框 |
| 系统托盘 / 全局快捷键 | 无 | 有 |
| 待升级 | — | 开机自启、.vault 文件关联 |
